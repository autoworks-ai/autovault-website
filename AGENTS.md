# AGENTS.md

This file provides guidance to Codex and other non-Claude agents working
in this repository. Claude Code reads `CLAUDE.md` instead; the two files
should stay in sync.

The full project context, commands, architecture map, and conventions
live in [`CLAUDE.md`](./CLAUDE.md) — read that first.

## Codex-specific notes

- The repo's PR workflow uses Conventional Commits in PR titles
  (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`). The `Lint PR Title`
  check will fail otherwise.
- Local CI gate: `npm run ci` runs typecheck, vitest, the Pages Functions
  build, and the VitePress build. Run before pushing.
- Cloudflare Pages preview deploys are generated by CI on every PR.
  Preview URLs appear in the PR checks — verification of UI changes
  should happen against the preview, not local dev only.
- Stripe is in test mode. Don't introduce `sk_live_*` keys anywhere.
- D1 schema is migration-based; never edit existing migration files.
  New schema goes in `migrations/0002_*.sql` and onward.
